# 日本語Webデザイン補助のLPを整える

2026-11-09の本人の依頼「LPっぽくシンプルでこだわったデザイン」を対象とする。公開版72ccb0fのWebガイドは、導入より先に64項目の一覧が長く続き、情報の優先順位が分かれにくい。紙色・墨色・緑、明朝の組版見本、フロート型ヘッダーを継承し、LPの読み順と文字の階層を整理する。

## 完成状態

最初に「いつものデザインスキルに、日本語の調整を。」と伝え、見本、使い方、根拠、詳しいガイドの順に進む。主操作を導入へ統一し、64項目の検索ガイドは後半に残す。装飾カードを増やさず、広い余白、異なる面、細い罫線、文字の役割で切れ目をつくる。小さなラベルはコンパクトに、複数行の説明は読みやすい行高とする。サイズだけで行高を単調に縮めない。

## 不変条件

- LP-CONTENT: 64項目・39資料、根拠の分類、検索・交差条件・0件・リセット、詳細の開閉、導入コマンド・コピー・ZIP・SHA-256を保持する。ガイドのIDと既存アンカーも保つ。
- LP-TYPE: balance、見出し全体のkeep-all、幅を合わせるための固定改行を加えない。実文の通常の折り返しと、用途別のサイズ・行高・行幅で整える。比較用の同じ文章と前後の違いは保持する。短い「日本語の調整を。」だけは意味のまとまりとしてinline-blockにし、最大幅100%と内部の通常折返しを保つ。
- LP-LAYOUT: ヘッダーと本文の外幅をそろえ、押せる操作は44px以上を保つ。320/390/768/1280pxと実Chrome200%で、横はみ出し・意図しない文字欠け・操作の遮蔽がない。
- LP-PACKAGE: catalog.json、スキルと生成資料、v1.0.1タグ、ZIPのbyteを保持する。サイトの編集はWebのcommitとWorker版で追跡し、配布物の版を偽らない。

## 検証と停止

文言とレイアウトの変更は、旧版の見本・カタログ・配布物・アンカーを比較する。有限の項目集合には既存の検査を使い、ページの構成と見出し・導入順序も検査する。実ブラウザの算出スタイルとテキスト矩形、操作、スクリーンショットで表示を確認する。欠落や順序違反の変種を同じ判定が検出することを確認する。権限・並行処理・永続データを変更しないため新しいSMT/TLA+は追加しない。利用者試験の改善率や全環境の保証には広げない。

必須build/test・Biome・日本語検査・機密検査・PR CIを通し、通常のマージと既存nandarona接続で配備する。本番のHTML/CSS・検索・コピー・実200%を再確認する。必要な操作の欠落や未説明の差分は公開前に修正する。

AI向けの資料は `/for-ai/` に分け、スキル・JSONカタログ・llms.txt・適用条件をまとめる。LPとガイドは人が読む・試す画面として保つ。相互の入口と直接の資料URLを保持する。
