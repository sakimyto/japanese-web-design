# v1.0.1の公開範囲

2026-11-08の「ブラッシュアップしきってリリース」に基づく。編集元を専用repositoryへ移し、スキル、出典付きガイド、比較例、ZIP、導入方法を公開する。sakimyto.comには実験の記録を登録する。

## 仕様と現状

初期版は64項目・39資料で、配布構造の検査は通っている。生成AIの出力の改善、実ブラウザの表示、CLI導入、公開配信は未検証だった。公開版はこれらを混同せず、確認できた機能と効果の仮説を分ける。

元のprivate repositoryの履歴や他の作業のファイルは公開しない。自作の許可した成果物だけを新しいrepositoryへ移す。元の作業領域に残る未確定の変更を、公開版へ混ぜない。

## 完成状態

- sakimyto/japanese-web-designの公開repository、v1.0.1のタグとZIPを提供する。
- 標準のskills CLIで、隔離したテスト用projectへ導入でき、全参照ファイルが揃う。
- 公開Webガイドでルールを検索・分野別に絞り込み、修正例と導入方法を確認できる。
- HTML、CSS、JavaScript、スキル配布物を検査し、接続済みChromeで主な操作と折り返しを確認する。
- 本体サイトのラボ記録、日英のSEO資料を更新し、本番のリンクを読み戻す。

## 不変条件

EVIDENCE、CONDITIONAL、SYNC、PACKAGE、REPEATABLEを初期版から引き継ぐ。追加のSITEは、全ルールを欠落なくHTMLへ出し、未信頼文字列をHTMLとして実行させず、検索とカテゴリの交差条件が一致すること。INSTALLは、導入先とタグに対応する配布内容が一致すること。RELEASEは、公開タグ、配布ZIP、サイトのバージョンが一致すること。有限のルール・カテゴリ・ファイル集合は全列挙し、壊した変種を検出する。実ブラウザの表示と操作は直接確認する。

## 停止と復旧

必須CIの失敗、意図しないデータ公開、導入時の参照欠落は公開前に修正する。公開後に重大な不具合があれば、直前の検証済みcommitを再配備し、配布物を修正バージョンへ更新する。タグを上書きせず、旧配布物の取り違えを防ぐ。新しい認証、課金、外部AIの追加実行は行わない。生成効果については自己評価を外部の独立評価と呼ばない。
