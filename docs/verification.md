## ブラウザで確認したこと

既存のChrome接続を使い、ローカルのWranglerで表示した。320、375、768、1280 CSS pxで横のはみ出しは検出されなかった。日本語の実文、見出し、和欧混植の見本、本文と条件のまとまりを表示で確認した。

「IME」の検索は2項目、日本語入力の分野との交差はF01の1項目になった。0件の案内、リセット、ルールへのリンクからの展開、Enterキーでの開閉、導入コマンドのコピーが機能した。対象タブのエラー・警告は0件だった。

比較見本は、同じ文章と書体を使って行高と字間を調整した自作例。追加スキルの有無による生成実験ではない。文章の条件を削って見た目を揃える例にはしていない。
